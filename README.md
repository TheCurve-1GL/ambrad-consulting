# Ambrad Consulting website (engineering and planning)

Source for www.ambradconsulting.com, served by GitHub Pages from the `main` branch root.
This is Ambrad Consulting's engineering site: Flood Risk Assessments and planning support documents.
The digital and AI transformation site is www.ambradconsulting.uk (repo `ambrad-consulting-uk`).

- `index.html` home page.
- One page per document, each aimed at its own Google search: `flood-risk-assessment.html`, `drainage-strategy.html`, `design-and-access-statement.html`, `sustainability-energy-statement.html`, `travel-plan.html`.
- `assets/` shared stylesheet, the navy and teal Ambrad Consulting report logo and favicon.
- `sitemap.xml` lists every page for Google. `CNAME` sets the custom domain. `.nojekyll` serves files as they are.

Changes to `main` publish straight to the live site.
