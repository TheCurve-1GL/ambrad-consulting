# Ambrad Consulting website

Source for www.ambradconsulting.com, served by GitHub Pages from the `main` branch root.

- `index.html` is the whole site (single page, self-contained apart from Google Fonts).
- `CNAME` sets the custom domain.
- `.nojekyll` tells GitHub Pages to serve files as they are.

Changes to `main` publish straight to the live site.
