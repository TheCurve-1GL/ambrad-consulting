# Ambrad Consulting website

Source for www.ambradconsulting.com, served by GitHub Pages from the `main` branch root.

- `index.html` is the home page (self-contained apart from Google Fonts).
- One page per service, each aimed at its own Google search: `systems-engineering.html`, `operational-excellence.html`, `ai-consultancy.html`, `asset-management.html`, `flood-risk-assessment.html`. They share `assets/site.css`.
- `assets/` holds the shared stylesheet, the coral hexagon mark and the navy and teal report logo (used on the flood risk page).
- `sitemap.xml` lists every page for Google.
- `CNAME` sets the custom domain.
- `.nojekyll` tells GitHub Pages to serve files as they are.

Changes to `main` publish straight to the live site.
