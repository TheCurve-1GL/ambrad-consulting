# Ambrad Consulting website (engineering and planning)

Source for www.ambradconsulting.com, served by GitHub Pages from the `main` branch root.
This is Ambrad Consulting's engineering site: planning support documents, and asset and contract advice for infrastructure owners and operators.
The digital and AI transformation site is www.ambradconsulting.uk (repo `ambrad-consulting-uk`).

- `index.html` home page.
- One page per service, each aimed at its own Google search.
  - Planning: `flood-risk-assessment.html` (includes drainage), `design-and-access-statement.html`, `sustainability-energy-statement.html`.
  - Infrastructure owners and operators: `strategic-asset-management.html`, `systems-engineering-mbse.html`, `operational-excellence-infrastructure.html`, `pfi-contract-reviews.html`.
- `assets/` shared stylesheet, the navy and teal Ambrad Consulting report logo and favicon.
- `sitemap.xml` lists every page for Google. `CNAME` sets the custom domain. `.nojekyll` serves files as they are.

Changes to `main` publish straight to the live site.
